# Memes-Database — Logo Concepts, v1

First independent logo round, created 6 October 2026. These are original, authored SVG concepts for review; none is adopted as the project identity. No application code or implementation assets changed, and no commit or push was made.

## Context and assumptions

The repository currently contains shared AI guidance rather than an implemented product or established identity. The name suggests a planned collection or archive of memes. This round assumes a playful public collection with an emphasis on finding and saving expressive content; it does not imply that search, accounts, uploads, or database features have been implemented. The exact display name is **Memes-Database**. No existing meme character, internet likeness, or third-party brand is reused.

`00-concept-sheet.svg` is an editable 1600 × 1000 comparison sheet on a paper-colored canvas. It presents all three directions, their palettes, and a simplified monochrome 32-pixel mark sample for each. It is a flat design comparison, not a product mockup. `00-concept-sheet.png` is the companion raster export for convenient viewing; the SVG remains the editable master.

## Exact palette

- Electric Violet: `#6938EF`
- Coral: `#FF675B`
- Ink: `#1D182A`
- Lilac: `#BDA7FA`
- Paper: `#FFF9F1`
- Sheet rules: `#DCD5E4`
- Sheet secondary text: `#686171`

Archive Grin leads with Coral and supports it with Violet and Lilac. M Signal leads with Violet and uses Coral as its accent. Byte Cabinet leads with Ink and uses the colored tiles to distinguish the archive's contents. Standalone SVGs and lockups have transparent surrounding canvases; the comparison sheet intentionally has a Paper background. The tiny monochrome examples simplify interior detail rather than merely recoloring the full mark.

## Editable artwork and typography

Every mark is built from editable SVG paths, rectangles, and circles. Each SVG has an accessible title and description and a useful `viewBox`. Lockups keep the wordmark as editable text using `Avenir Next`, then `Avenir`, then `Arial`, then `sans-serif`. No font is bundled. A fallback may change width, letter spacing, or weight; choose and license a production typeface before outlining an adopted wordmark. The sheet uses the same fallback stack. Detailed full-color marks are intended for medium and larger uses; the monochrome samples show the proposed small-size simplification, not a tested favicon asset.

No browser checks, tests, builds, or visual verification were run, following the project instructions. Selection, refinement, and adoption remain with the user.
